# friendship-app 🤝

> a one-question website. just one.

## what it does

- asks the most important question
- the **No 😢** button evades the cursor every single time they try to click it, with a different roast each time
- the **Yes ✦** button triggers a full acceptance screen with "friendship renewed."
- glitch effects, floating particles, noise texture, and zero cheesiness

## setup

```bash
npm install
npm start
```

Opens at `http://localhost:3000`

## build for production

```bash
npm run build
```

## stack
- React 18
- Pure CSS animations (no extra libraries)
- Google Fonts: Unbounded + Space Mono
